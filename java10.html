Struktogramm und Java

double wert, ausgabe;
boolean in_celsius;
wert = IO.getDouble("Temperaturwert?");
in_celsius = IO.getBoolean("In °C gegeben?");
if (in_celsius) {
    ausgabe = wert * 1.8 + 32;
    System.out.println(ausgabe + " °F");
} else {
    ausgabe = (wert - 32) * 5.0 / 9.0;
    System.out.println(ausgabe + " °C");
}

Deine Übungswerkstatt


Die Aufgaben aus den Materialien zu Verzweigungen und Schleifen – mit Arbeitsaufträgen, Hilfen, Lösungshinweisen und einer eigenen Arbeitsfläche. Die Nummern entsprechen den Vorlagen. „Erledigt“ ist deine Selbsteinschätzung, keine automatische Bewertung.











Code-Training


Vervollständige kurze Java-Code-Fragmente. Trage nur die fehlende Anweisung oder den fehlenden Ausdruck ein und prüfe deine Ergänzung. Der Code wird hier nicht ausgeführt; die Aufgaben prüfen die erwartete Lösung.


Arbeite möglichst ohne die Lösungshinweise. Achte auf Datentypen, Klammern, Vergleichsoperatoren und Semikolons.









Fehlersuche


In jedem Programm steckt mindestens ein Fehler. Untersuche den Quelltext, verbessere ihn direkt im Editor und prüfe anschließend, ob die entscheidende Fehlerstelle korrigiert wurde.


Die automatische Kontrolle prüft die entscheidende Code-Stelle anhand einfacher Regeln. Sie ersetzt keinen Java-Compiler. Teste deine fertige Lösung zusätzlich in eurer Programmierumgebung.









Prüfungsvorbereitung


Ein gemischter Übungstest zu den Themen der Java-Werkstatt. Beantworte alle Fragen und lass dir anschließend eine Auswertung mit Erklärungen anzeigen. Du kannst den Test beliebig oft wiederholen.

Passender Java-Quelltext
Übersetzung, keine Prüfung: Der Editor setzt deine Bausteine in Java-Syntax um. Er prüft weder Datentypen noch Variablennamen, Initialisierung, sinnvolle Bedingungen oder Endlosschleifen. Die IO-Klasse für die Eingaben muss im Unterricht bereitgestellt werden. Teste den Code im Java-Editor.
