double wert, ausgabe;
boolean in_celsius;
wert = IO.getDouble("Temperaturwert?");

if (in_celsius) {
    ausgabe = wert * 1.8 + 32;
    System.out.println(ausgabe + " °F");
} else {
    ausgabe = (wert - 32) * 5.0 / 9.0;
    System.out.println(ausgabe + " °C");
}

Experiment: Warum funktioniert die Schleife?

Das Modell wählt eine ganze Zahl von 1 bis 100. Nach jedem Tipp wird die Bedingung für den nächsten Durchlauf sichtbar.

Vom Spiel zum Algorithmus

int eingabe = 0;
int geheimzahl = 0;
IO.show("Errate eine Zahl zwischen 1 und 100.");
geheimzahl = (int) (100 * Math.random() + 1);
while (eingabe != geheimzahl) {
    eingabe = IO.getInt("Ihr Tipp:");
    if (eingabe < geheimzahl) {
        IO.show("Zahl zu klein");
    } else {
        if (eingabe > geheimzahl) {
            IO.show("Zahl zu groß");
        } else {
            IO.show("korrekt!");
        }
    }
}
Die angezeigte Versuchszahl ist die Erweiterung aus Aufgabe 8a. Im Originalprogramm gibt es diesen Zähler noch nicht. Browser-Eingaben im Modell ersetzen nur die IO-Dialoge.

Struktogramm-Werkstatt


Baue einen Ablauf aus Blöcken. Ein Struktogramm ist kein Flussdiagramm: Es hat keine Pfeile und keine frei schwebenden Entscheidungsrauten. Verschachtelung und Aufteilung der Rechteckfläche zeigen die Struktur.


So arbeitest du: Füge Bausteine hinzu. Bei „Falls“ bearbeitest du Wahr- und Falsch-Zweig getrennt; bei einer Schleife ihren Rumpf. Die Reihenfolge lässt sich mit ↑ und ↓ ändern. Variablen deklarierst du im eigenen Feld – sie erscheinen wie im Skript nicht im Struktogramm, sondern im Java-Code.
